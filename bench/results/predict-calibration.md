## 2. Per task: the predictor explains little

Elapsed seconds of each implementer dispatch versus the predictor, leave-one-run-out (n = 43 dispatches):

| model | mean abs error s | bias s (predicted - actual) |
|---|---|---|
| current predictor | 90.7 | -21.1 |
| predictor x fitted scale | 104.9 | -51.4 |
| OLS on loc, components, slow tests | 102.9 | +13.8 |

**Finding 2.** Per dispatch the predictor is not far off on average (bias -21 s) but it explains little: R^2 = 0.18 (a fit on loc, components and slow tests reaches 0.32 in sample, and its leave-one-run-out error is no better). A dispatch takes a median 138.9 s with a spread of 135.6 s; LOC correlates at 0.54. The fitted per-component term is negative (components and LOC are collinear), so do not copy it. Proposed coefficients (n=43, NOT applied): base 54.0 s, 50.6 s per 100 LOC, -21.7 s per component, 22.7 s slow tests.

Total time error: predictor 41% mean (worst 50%), calibrated 14% mean (worst 29%). Build span error: predictor 33% mean, calibrated 18% mean (worst 40%).

**Finding 3.** What still cannot be predicted from the plan: (a) the after-build phase (506 to 1055 s) depends on how many reviews and fixes the run needs; (b) the build span follows what the coordinator did, not the plan: tasks were batched or merged after the plan was written (dispatched/planned: v2 11/11, v3 8/11, w1 4/6, w2 6/8, w3 6/9), edges were not honoured (v2 ran T11 before T10 was done), and one slow dispatch can set the whole span (v3: one 480 s dispatch = the 481 s build). Rebuilding the span from fitted task times over the plan graph was tried (agent cap, dispatch lag) and was worse (65 to 76% mean error against the predictor's 33%), so the calibration scales the predictor's build instead. With 5 complete runs this is a range estimate, not a point estimate.

## Caveats

- Five complete runs and 43 dispatches, one project (combo, Python). Every figure for a run is predicted without that run's data, so the errors are honest, but wide.
- Dispatch features come from the final plan file; where a run batched or merged tasks after writing the plan, features and dispatch do not match.
- Not applied to predictor.json or `schedule`; those are owned elsewhere.
